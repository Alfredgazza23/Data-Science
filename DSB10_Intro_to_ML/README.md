## Что можно проверить в коде

В `ex03` сравниваются Logistic Regression, SVM, Decision Tree и Random Forest. Параметры леса подбираются через GridSearchCV на обучающей части. Итоговая модель сохраняется через joblib, затем загружается и используется для повторного предсказания.

Стек раздела: Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, joblib, Jupyter Notebook.

## Данные и запуск

CSV-файлы находятся в [data](data/). Ноутбуки запускаются из своих папок `ex00`–`ex05`, поэтому используют пути вида `../data/...`.

В `ex02` предусмотрено сохранение `../data/dayofweek.csv`. В репозитории также есть готовый файл `dayofweek (1).csv`; перед отдельным запуском `ex03` нужно получить ожидаемое имя файла. Порядок подготовки описан в [инструкции запуска](../docs/RUNNING.md).

Сохранённые выводы иллюстрируют выполнение упражнений. Условия и порядок предобработки нужно учитывать перед использованием их метрик как итоговой оценки модели.
