# ML5 — собственные деревья решений и ансамбли

Продолжение задачи классификации проблемных покупок автомобилей. Цель — реализовать деревья и ансамбли, исследовать их параметры и сравнить с готовыми библиотеками.

[Открыть ноутбук](ML5_Decision_trees.ipynb) · [Предыдущий проект: базовые классификаторы](../ML4_Classification%20problems/README.md) · [Все проекты](../README.md)

## Данные и валидация

Используется `training.csv` из [Don't Get Kicked!](https://www.kaggle.com/competitions/DontGetKicked/data): 72 983 записи, целевая переменная `IsBadBuy`.

Разбиение выполняется по дате покупки `PurchDate` на train, validation и test. Для сравнения моделей анализируются качество на каждой части и разрыв между обучающей и валидационной оценками.

## Что реализовано

- Собственные дерево-классификатор и дерево-регрессор с поиском разбиений по гистограммам.
- Random Forest: бутстрэп-выборки, случайный выбор признаков и усреднение вероятностей.
- Градиентный бустинг для бинарной классификации на собственных деревьях.
- Extra Trees и сравнение со Scikit-learn.
- Эксперименты с глубиной, числом деревьев и числом интервалов для поиска разбиений.
- Сравнение с CatBoost, XGBoost и LightGBM, включая вариант CatBoost с исходными категориальными признаками.

## Сохранённые результаты

Сравнение на validation из таблицы ноутбука:

| Модель | Gini по текущей формуле ноутбука |
|---|---:|
| Собственное дерево | 0,4286 |
| Собственный Random Forest | 0,4675 |
| Собственный градиентный бустинг | 0,4713 |
| LightGBM | 0,4531 |
| XGBoost | 0,4847 |
| CatBoost с исходными категориями | 0,4951 |

**Особенность метрики:** в текущем коде используется `abs(2 * ROC_AUC - 1)`. Таблица воспроизводит сохранённые значения этой функции. Для стандартного нормированного Gini следует убрать модуль и пересчитать результаты.

Основной практический результат — реализации алгоритмов и сравнение их поведения с библиотечными моделями. Время обучения в исходных таблицах зависит от окружения и не используется здесь как универсальный показатель производительности.
