## Что реализовано в упражнении с Pipeline

- `FeatureExtractor`: извлечение часа и дня недели из timestamp.
- `MyOneHotEncoder`: кодирование категорий и масштабирование числовых признаков.
- `TrainValidationTest`: разбиение на train, validation и test.
- `ModelSelection`: сравнение моделей после поиска гиперпараметров.
- `Finalize`: итоговая оценка и сохранение модели.

Стек: Python, NumPy, Pandas, Scikit-learn, Matplotlib, Seaborn, tqdm, joblib, Jupyter Notebook.

## Ограничения текущей версии

В `ex04` вызов `preprocessing.fit_transform(df)` выполняется до разбиения данных. Для корректной оценки предобработку следует обучать на train, а при GridSearchCV — заново внутри каждого обучающего фолда. Результаты текущего варианта требуют пересчёта после исправления.

Для части упражнений отсутствуют подготовленные файлы `dayofweek.csv` и `day-of-week-not-scaled.csv`. В `ex04` также ожидается имя `checker_submits.csv`, тогда как загруженный файл называется `checker_submits (1).csv`.

Ноутбуки сохранялись в старом окружении; в `ex03` используется параметр `base_estimator` у BaggingClassifier. Совместимость вызовов с установленной версией Scikit-learn необходимо проверить перед повторным запуском.

Источники данных, ожидаемые пути и порядок подготовки приведены в [инструкции запуска](../docs/RUNNING.md).
